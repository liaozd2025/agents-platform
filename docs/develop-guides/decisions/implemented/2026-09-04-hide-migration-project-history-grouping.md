# 隐藏迁移项目并按时间展示历史会话

状态：implemented
类型：feature
Owner：web/src/components/ConversationNavSection.vue

## 问题

H5 历史会话必须绑定 Project，但用户不应把内部迁移项目当作普通项目管理；会话仍需出现在常规历史列表中。

## 决策

项目列表接口过滤 H5 迁移专用幂等键，保留数据库中的 Project、权限和 Workdir 绑定。前端将未出现在可见项目列表中的会话放入历史区域，并按最近、一周前、一月前分组。

## 替代方案

- 将会话的 `project_id` 置空：违反当前数据库非空约束。
- 删除迁移项目：会破坏会话的 Project/Workdir 外键关系。
- 继续展示“OA历史会话”项目：用户体验与普通历史列表不一致。

## 后果

迁移项目不再出现在项目选择和侧边栏项目区域；历史会话仍可按用户权限访问。超过一月的会话归入“一月前”分组。

## 验证

- 后端项目服务单元测试通过。
- 前端项目会话分组测试覆盖迁移会话和时间分组边界。
