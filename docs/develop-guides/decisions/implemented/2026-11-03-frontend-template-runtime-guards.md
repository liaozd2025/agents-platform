# 前端模板引用与运行时回归检查

状态：implemented
类型：bug-fix
Owner：frontend/eslint.config.js

## 问题

智能体列表模板引用不存在的分组变量，导致列表渲染异常，随后页面切换继续报错。搜索状态、图标、技能套件及账户复制入口也存在未定义引用。仅检查脚本语法、构建和组件 setup 无法证明真实模板能够渲染。新建会话也未传递界面选中的模型，默认模型不可用时会在发送首条消息前被拒绝。

## 决策

### 实现方案

模板消费当前组件或 store 的真实接口。搜索按钮读取导航组件公开的搜索状态；智能体卡片按功能权限与单项 `can_run` 展示对话入口；上传提示使用队列拥有的并发常量。遗漏的组件显式导入，账户复制复用剪贴板工具。图谱详情删除失去实现的父级点击监听，保留子组件的展开和收起；会话删除无法触达的旧重试监听，当前操作栏仅提供复制与来源，提交失败重试仍走 Input 流程。

新建会话在首次尝试时冻结选中模型，并通过 Public Session 的 `agent.model` 传递；响应丢失时与幂等键、审批模式一并重放，不混入后续编辑。前端没有模型标识时省略覆盖，由后端解析默认值。

现有 lint 启用 `vue/no-undef-properties` 和 `vue/no-undef-components`。全局注册的 Ant Design 与 Router 组件允许由应用装配提供。回归测试渲染真实智能体卡片、套件与账户模板，并断言可见内容、权限状态及复制结果；规则负例含未定义属性与未导入组件。

## 替代方案

不采用可选链或空函数掩盖失配，否则页面可能不崩溃但入口仍无效。不只扩大 setup 单测数量，因为空渲染不能触达模板中的错误。

## 后果

新引入的未定义模板引用会阻断现有 lint 检查。静态检查不覆盖后端响应、浏览器生命周期或完整业务链路；SSR 回归也不能替代真实浏览器验收。

## 验证

`frontend/test/unit/templateRuntime.test.js` 覆盖真实卡片渲染、对话入口权限、套件安装计数、账户复制成功与失败，以及 lint 规则负例。`threadCreation.test.js` 与 `publicAgentApi.test.js` 覆盖模型冻结、幂等重放和实际请求体；恢复缺失字段会使相关断言失败。使用现有前端 lint、unit 和 build 命令验证。浏览器中已观察到原始渲染错误；修复后逐页浏览器验证受自动化连接中断影响，仍待完成。
