# 角色功能权限与组织数据范围分离

Yuxi 采用“RBAC 功能权限 + 组织数据范围”的双轴授权：角色回答用户能执行什么操作，数据范围回答操作能够覆盖哪些组织数据，最终授权必须同时满足两者；组织节点筛选默认覆盖节点自身及其全部后代，直属查询必须显式表达。角色分为受保护的 `superadmin`、`admin`、`user` 内置角色与自定义角色；允许多个 `superadmin`，但始终至少保留一个。

`superadmin` 的管理域为整棵组织树；归属集团根的 `admin` 管理整棵树，其他 `admin` 管理其归属节点子树。该决定取代 ADR 0001 中“`admin` 管理域恒为整棵树”的阶段性结论；知识库、智能体和 Skill 的资源共享继续使用独立的共享范围，不因角色数据范围而自动扩大。

功能权限使用稳定的“资源 + 操作”标识，并以服务端权限目录为事实来源；菜单、路由和按钮只投影服务端授权。用户可拥有多个普通角色并合并其权限，`superadmin` 独占；角色采用平铺模型，不建立角色继承，复用通过复制角色完成。

所有现有 `admin` / `superadmin` 管理端点必须在同一发布边界内迁移到功能权限检查，可以拆分实现提交，但不发布新旧鉴权并存的中间状态。知识库、智能体和 Skill 继续由功能权限与既有资源共享共同判定，任何角色或数据范围都不能绕过具体资源的共享范围。

角色保存默认数据范围；用户角色分配选择继承默认值或保存个性化覆盖，不建立脱离角色分配的用户全局数据范围。管理类组织树只返回授权子树及其必要祖先，查看全集团组织目录需要独立功能权限；每个有效用户至少保留一个角色，本地创建与 OIDC 首次登录默认分配内置 `user`。

实时授权始终按当前组织关系计算，但 Dashboard、审计与历史报表按业务事件发生时保存的组织快照归属，避免人员调动改写历史统计。三个内置角色的标识和权限均只读；业务差异通过复制为自定义角色实现。

数据范围固定为无数据、仅本人、本组织及下级、指定组织及下级、全部数据。用户角色分配的个性化覆盖只能缩小角色默认范围，扩大范围必须新增另一条角色分配；一次授权只在同一条分配同时拥有功能权限且覆盖目标数据时成立，禁止把不同角色的权限与范围交叉拼接。

授权采用默认拒绝和允许项并集，不引入显式拒绝。用户归属、组织树关系、角色权限或数据范围变化均从下一次请求起立即生效，不保留旧授权缓存；事件组织快照仅服务于历史统计，不参与实时授权。

Dashboard 与统计区分实时归属和历史归属：实时人员统计按当前组织树计算，调用、反馈、审计等历史业务按事件发生时的组织快照计算；资源的创建归属与共享可见分别统计。迁移前缺少快照的历史记录按当前用户归属回填，并明确标记为推算值。

功能权限目录由服务端代码维护，权限标识固定为 `resource:action`；数据库只保存角色、角色权限关联和用户角色分配，不提供自定义权限标识。只有 `superadmin` 可以创建、修改和停用角色；具备 `user:role_assign` 的其他用户只能在自己的数据范围内分配非超级角色，并且目标角色的功能权限和分配范围都不能超出操作者自身的有效授权。

内置角色不能停用或删除。自定义角色采用停用而非硬删除；仍有用户分配时必须先迁移用户角色。角色、功能权限、默认数据范围和用户角色分配的变更必须写入安全审计，保存操作者、时间、目标和变更前后值；授予或撤销 `superadmin` 必须填写原因。

系统设置中的现有权限入口统一为“角色与权限”，提供角色列表以及基本信息、功能权限、默认数据范围、成员四类详情；用户管理支持多角色分配和对单次分配的数据范围进行收窄。数据范围“仅本人”只适用于存在明确创建人、负责人或用户本人字段的数据；没有所有者字段时按无数据处理，不根据其他字段猜测。

存量 `users.role` 通过一次性数据库迁移转换为角色分配，前后端同步改用角色数组；迁移后删除旧字段，不保留双写、运行时兼容或回退逻辑。内置 `superadmin` 拥有全部功能权限和全部数据，内置 `admin` 保留现有管理功能并默认覆盖本组织及下级，内置 `user` 保留普通功能且组织数据默认仅本人；根节点 `admin` 因组织层级自然覆盖整棵树。

服务端每次请求加载一次当前用户的角色分配、功能权限和数据范围，形成请求级授权上下文；不建立跨请求权限缓存。缺少功能权限返回 `403`，目标不在数据范围或资源不可见返回 `404`，角色仍被占用等状态冲突返回 `409`。

普通组织筛选统一解释为所选节点自身及全部后代，直属查询必须使用显式参数。管理用组织树只返回授权子树及其必要祖先。本次变更以一次发布为边界完成数据库迁移、全部管理端点鉴权、用户与 Skill 子树查询、角色管理界面以及 Dashboard 组织统计与快照；不引入角色继承、显式拒绝、字段级权限或权限缓存。
