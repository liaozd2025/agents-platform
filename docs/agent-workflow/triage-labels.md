# Triage 标签

skills 内部使用五个规范化的 triage 角色。下表把这些角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| skills 中的角色   | 本仓库标签        | 含义                             |
| ----------------- | ----------------- | -------------------------------- |
| `needs-triage`    | `needs-triage`    | 待评估，尚未确认是否要做         |
| `needs-info`      | `needs-info`      | 等待提出方补充信息               |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可直接交给 AFK agent   |
| `ready-for-human` | `ready-for-human` | 需要人工实现                     |
| `wontfix`         | `wontfix`         | 不会处理                         |

当某个 skill 提到一个角色（例如 "apply the AFK-ready triage label"），使用本表右列对应的标签字符串。

右列可按团队实际习惯修改；改后无需改动任何 skill。
