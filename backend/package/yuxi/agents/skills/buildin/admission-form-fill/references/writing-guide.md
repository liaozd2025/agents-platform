# 药品入院申请表 · 标准书写指南与颗粒度规范 (Writing Guide)

> **核心定位**：本指南用于规范 Agent 在起草各类栏位时的**语言风格、表达颗粒度与论证结构**。
> **事实边界声明**：本指南中的任何示例仅用于展示“格式与结构”，**严禁将本文件中的任何药名、规格、价格数据直接作为待申报药品的事实！所有事实必须遵循统一来源优先级**。

---

## 一、 事实来源模型与信任优先级

在处理药品事实与申报数据时，Agent 必须遵循以下五级信任优先级：

```text
Level 1: 当前模板明确限定规则 (如表尾注注明“禁止填写商品名或生产企业”)
    >
Level 2: 用户在当前会话中明确确认的具体值 (user_confirmed，如议价采购价、特定包装规格)
    >
Level 3: 当前项目/批次中已人工审核通过的同产品既有确认事实 (project_confirmed)
    >
Level 4: 权威知识库检索获得的客观证据 (knowledge)
    >
Level 5: 本指南与参考范例文档 (仅提供写作范式，不得作为事实数据源)
```

> **应用说明**：若用户明确指出“本次申报价格按 62.30 元/盒填写”，虽然知识库中可能没有该价格，Agent 应将其作为 `user_confirmed` 事实予以采纳并标注来源，不得死板地归为 `missing`。

## 二、 各栏填写颗粒度标准

| 栏位类别 | 栏位名称 | 规范写法基准 | 核心边界与纠偏红线 |
|---|---|---|---|
| **A 类** | 药品通用名 | 药典规范通用名（如：`酮洛芬凝胶贴膏`） | 除非栏目明确要求“通用名（商品名）”，否则**严禁擅自附加商品名**。注意检查表尾红线。 |
| **A 类** | 商品名 | 注册商标名称，若无则**留空** | 无商品名时留空，**不写“无”、“/”、“暂无”**。 |
| **A 类** | 剂型 | 《中国药典》标准制剂名称（如：`贴膏剂`） | 严禁使用俗称（如“膏药”）。 |
| **A 类** | 规格 | 完整物理与化学技术规格（如：`每贴（14cm×10cm）含膏体13g，含酮洛芬30mg`） | 尺寸、膏体量、主药含量三要素写全，严禁简写为“13g/贴”。 |
| **A 类** | 包装规格 | 明确各级包装层级（如：`4贴/袋×2袋/盒`） | 写全袋、盒两层关系，不只写“8贴/盒”。 |
| **A 类** | 批准文号 | 完整国家药品批准文号（如：`国药准字H20233229`） | 完整字母与年份数字，不可省略。 |
| **A 类** | 生产企业 / MAH | 营业执照标准全称（如：`湖南九典制药股份有限公司`） | 严禁使用简称。**优先遵循表尾注**（若医院模板注明“禁止填生产企业”，则跳过不填）。 |
| **A 类** | 采购价格 | 挂网价带单位（如：`69.44元/盒` 或 `￥8.68/贴`） | **数值与单位必须严格匹配**。若栏头已有“元”，单元格填纯数字；若无单位则补全单位。 |
| **A 类** | 适应证 | 说明书【适应证】核准文字（一至两句话提炼） | 提炼核心适应证，不照搬整页说明书。 |
| **A 类** | 用法用量 | 给药途径 + 给药部位 + 单次剂量 + 频次（四要素齐备） | 范例：`外用，贴敷患处，每次一贴，一日2次。` |
| **A 类** | 不良反应 | 优先提取硬数据（样本量、不良反应例数、百分比） | **必须尊重来源事实**：若临床研究为 `6908例中141例(2.04%)`，如实记录；若仅有定性描述（“偶见局部皮肤瘙痒”），则如实陈述定性结果，**严禁自行编造样本量与百分比**！ |
| **B 类** | 申请理由 | 优先按表格追问作答；无要求时套用六段式论证骨架 | 详见第三节。 |
| **C 类** | 签名/审批/意见 | 申请人签名、科室意见、药事会审核、院领导批示 | **绝对不代填**！一律保留原样空白。 |

## 三、 申请理由论证骨架 (六段式范式)

当表格「申请理由 / 引进原因 / 临床必要性」栏位没有特殊追问时，采用以下六段式结构：

```text
1、政策性：医保准入类别（国家医保甲/乙类）、是否国家谈判品种（国谈）、是否国家集采/基药目录。
2、必要性：在疾病防治谱系中的定位、临床用药需求缺口、一线用药地位。
3、优效性：临床试验客观疗效数据（如有效率、症状改善评分等）。
          【红线】：仅在存在明确直接对照（头对头）研究时，方可声明“疗效优于同类”；若无对照证据，仅如实阐述本品自身治疗效果。
4、安全性：作用机制优势（如局部透皮释药降低全身胃肠及心血管毒副作用）、不良反应率及转归。
5、经济性：单次费用与日治疗费用（如单贴8.68元，日均费用17.36元）。
          【红线】：仅在有确凿同类竞品价格数据时进行比价；若无竞品对比证据，严禁虚假声称“费用低于同类产品”。
6、依从性：剂型特征、使用便捷度（如亲肤固定贴不易脱落、用药频次低）。
指南推荐：
《权威指南/专家共识全称（发布年份）》：具体推荐陈述原文。
【红线】：若原文明确标注了推荐强度与证据等级（如：推荐强度1，证据等级A），必须完整保留；若原文未标注评级，按原文如实呈现，严禁自行杜撰评级！
```

## 四、 特殊栏位与表格红线

1. **评分表填写准则**：
   - 包含《药品遴选评分表》时，**仅填写属于“临床申请科室自评”的列/项**；
   - **绝不代填“药学部复评得分”、“专家委员会评审”、“一票否决项”**；
   - 证据缺失的自评项：若评分细则未明确规定“无证据计0分”，则状态设为 `missing` 并向用户高亮，**不擅自直接填 0 分**。
2. **表尾“注”的最高优先级**：
   - 部分医院模板在文档末尾加注红线条款（如：“*请勿在申请表中填写商品名或生产企业名，否则本表作废*”）；
   - 一旦识别到模板禁令，立即执行跳过（`skipped`）。

## 五、 单元格排版美学与分段呈现范式 (Typography & Layout Aesthetics)

医院药事委员会与评审专家在审阅纸质或电子版申请表时，极度关注文本的可读性与呼吸感。**严禁将包含分点、序号、多层级的信息挤压为单个庞大的文本块！**

### 1. 核心排版五大金律

| 金律 | 规则说明 | 反面案例（严厉禁止） | 正面规范 |
|---|---|---|---|
| **律 1：逢点必分段** | 遇到序号（1. 2. 3.）、小标题（一、二、三、）、条目（•）时，**必须分为独立段落**。 | `1. 指南A推荐...； 2. 指南B推荐...； 3. 指南C...` 连缀成一段 | 每个序号独占一个 Paragraph，段首对齐。 |
| **律 2：小标题加粗** | 模块引导词、序号标签必须加粗，形成层次化的视觉抓手。 | `不良反应：用药部位红肿...禁忌：孕妇禁用...` 均无加粗混杂一团 | **【不良反应】**、**【禁忌症】** 独立加粗置于段首。 |
| **律 3：层级缩进** | 二级细项（如 RCT 研究的具体参数）使用符号缩进或二阶编号。 | 研究人群、干预、主要结果混在一句话中 | 使用 `•` 符号进行次级信息分行罗列。 |
| **律 4：呼吸感间距** | 段落行距控制在 1.15~1.25 倍，段后设置 2~3pt（或逻辑模块间空一行）。 | 行与行紧贴，文字压迫感严重 | 模块分明，留白舒适，长时间阅读不疲劳。 |
| **律 5：防文字裁切** | 写入长篇论述后，表格单元格行高必须为自动适应（Auto）。 | 误设固定行高（Exactly），导致大段文字被截断 | 确保 Word 预览或导出 PDF 时所有文字完整可见。 |

### 2. 四大高密度栏位标准排版样板

#### 样板 1：国内外诊疗指南 / 共识推荐意见
```text
1. 《早期膝骨关节炎诊断与非手术治疗指南（2024版）》（童培建）/《膝骨关节炎中西医结合诊疗指南（2023年版）》：
   推荐经非药物治疗无效时，可根据膝关节疼痛情况选择中成药外用治疗，主要包括各种贴膏、膏药等（证据等级：Ⅰ级；推荐强度：强推荐）。

2. 《慢性腰背痛康复中国疼痛科专家共识（2021版）》（童培建）：
   推荐针刺时可配合中药、艾灸等方法综合治疗（1A，强推荐），隔日治疗1次，5次为1个疗程，连续治疗2～3个疗程。

3. 《类风湿关节炎病症结合诊疗指南（2025年）》（阎小萍）：
   推荐寒湿痹阻证的治法为温经散寒，祛湿通络。

4. 《腹痛中医诊疗专家共识（2023年）》（唐志鹏）/《胃脘痛中医诊疗专家共识（2017）》（张声生）：
   推荐对于脾胃虚寒胃痛，采用外敷法治疗，主要取中脘穴、脘腹、脐下、足心等，以疼痛缓解为度。

5. 《骨伤中成药学》（程少丹、肖涟波）：
   权威教材明确收录本品用于原发性痛经之温经镇痛治疗。
```

#### 样板 2：支持引进的关键循证医学证据 (结构化 RCT)
```text
【研究一：代温灸膏在慢性胃炎（脾胃虚寒型）的临床应用】
• 研究类型：前瞻性、随机、对照临床研究（RCT）
• 研究人群：82 例脾胃虚寒型慢性胃炎患者
• 干预/对照：
  - 对照组：常规西药治疗（奥美拉唑 2周 + 阿莫西林、甲硝唑、果胶铋 1周）
  - 研究组：对照组基础上加用代温灸膏穴位贴敷（脾俞、肾俞、足三里、中脘等穴，1次/日，2-4h/次，共2周）
• 主要结果：
  1. 临床总有效率：联合组达 90.20%，显著高于西药对照组的 75.60%（提升 14.5%）；
  2. 中医症状改善：胃脘疼痛改善幅度为对照组的 3.2 倍，上腹不适改善为 2.5 倍，恶心呕吐为 3.0 倍。
• 研究结论：代温灸膏穴位贴敷辅助治疗可显著提升疗效，改善患者临床预后。
• 参考文献：何郁鹏. 代温灸膏穴位贴敷辅助治疗脾胃虚寒型慢性胃炎疗效观察 [J]. 养生保健指南, 2020, (52): 106.

【研究二：代温灸膏治疗驻军警卫部队士兵膝关节冷痛】
• 研究类型：前瞻性随机对照临床研究
• 研究人群：96 例北方沿海驻军警卫部队膝关节冷痛士兵
• 干预/对照：
  - 对照组：代温灸膏贴敷（膝关节髌韧带两侧，隔日更换，疗程 6天）
  - 实验组：扶他林乳胶剂涂抹（双氯芬酸钠，2g/次，2次/日，疗程 6天）
• 主要结果：代温灸膏组治疗 6天后膝关节疼痛（JOA）改善总有效率达 70.50%，镇痛起效迅速且耐受良好。
• 研究结论：代温灸膏单用治疗风寒阻络型膝关节冷痛具有确凿临床疗效与高度便利性。
• 参考文献：冯常智, 青祖宏, 高巍, 等. 扶他林乳胶剂与代温灸膏治疗部队士兵膝关节疼痛的疗效比较 [J]. 医学信息, 2011, 24(04): 1510.
```

#### 样板 3：安全性评价（模块化分段）
```text
【主要不良反应及发生率】
监测与临床文献数据显示，本品主要为用药部位局部轻微反应（如局部皮肤瘙痒、轻度红斑、丘疹或短暂灼热感），停药后均可自然消退，未见严重全身过敏或器质性损伤报告。

【禁忌症】
1. 孕妇禁用；
2. 对本品任何成分过敏者禁用；
3. 皮肤破损、溃烂、急性感染处禁用。

【特殊人群与用药注意事项】
1. 本品为外用贴剂，严禁口服；
2. 忌食生冷油腻食物，用药期间避免迎风受寒；
3. 儿童、年老体弱者应在医师指导下辨证使用；
4. 贴敷部位如有剧烈灼烧感、明显红肿水疱，应及时揭除并清洁局部皮肤。

【药物相互作用】
如需与其他外用贴剂或中药洗剂联合使用，请提前咨询主治医师或药师。
```

#### 样板 4：引进理由综述（六段式标杆排版）
```text
1. 【政策与医保属性】
国家医保目录乙类用药（温经理气活血散结剂），非国谈、非基药，契合公立医院中医优势专科与中药贴敷适宜技术推广政策。

2. 【作用机制与起效特性】
精选纯辛香温热类中药经典配方，依托穴位透皮给药，药力循经入络，温通经脉、散寒镇痛。创新替代传统艾灸温灸，兼具“穴位、药物、温灸”三位一体协同效应。

3. 【临床疗效与镇痛优势】
对早中期局部炎性反应及慢性风寒痹痛镇痛起效迅速、持续温热时间长，对慢性胃肠虚寒痛及风湿关节冷痛疗效独到。

4. 【给药途径与安全依从性】
外用经皮给药，不经过消化道分解，避免口服非甾体抗炎药（NSAIDs）的胃肠黏膜损伤及心血管风险，无肝肾代谢负荷，无明火烫伤风险，患者居家贴敷依从性高。

5. 【经济性与日均费用】
单贴挂网价格仅约 3.05 元，常规每日 2 贴，日均治疗费用仅 6.10~6.20 元（14天标准疗程约 86.80 元），患者经济负担极低。

6. 【同类竞品差异化定位】
相比吡罗昔康贴片等纯化学外用药，代温灸膏兼具“经络穴位调理”与“散寒温阳”双重作用，对于风寒阻络、虚寒泄泻、痛经等寒性病症针对性显著占优。
```
